# 港珠澳大桥智能安全监控系统 (Hong Kong-Zhuhai-Macao Bridge Smart Safety System)

本系统是一款基于 **Micro:bit V2** 主控板及 **KittenBot IO:bit V2** 扩展板设计的智能大桥安全监控与预警系统。系统模拟了港珠澳大桥在面临不同天气环境（光照强度、风速）以及交通状况（车辆计数、行车引导）时的全自动化智能协调配合。

---

## 📖 项目背景与目的

### 1. 项目背景
港珠澳大桥作为超大型跨海通道，面临极其复杂的海洋性气候。强风、暴雨、大雾以及昼夜交替等自然因素对行车安全构成了极大的威胁。本系统通过传感器阵列实时监测桥面环境，并动态控制路灯、交通信号灯、报警器和信息显示屏，实现高可靠性的大桥主动防御安全管理。

### 2. 设计目的
*   **大桥智能路灯系统**：通过高精密光敏电阻，实时感应昼夜交替，动态亮灭桥面 12 颗黄金色暖光路灯。
*   **大桥风速分级预警系统**：模拟监测风速大小，通过红黄绿三色交通信号灯、蜂鸣器进行视觉与听觉的双重分级行车指引（正常通行、减速慢行、强风禁行）。
*   **高精度车辆通过检测与计数**：使用超声波传感器实时探测桥面通过车辆，加入软件防重计计数锁及蜂鸣器通行提示音。
*   **大桥中央信息看板**：通过 I2C 1602 LCD 显示屏，实时、动态地展示当前通行车辆数、风速级别、昼夜状态和行车引导建议。

## 🛠️ 硬件配置与引脚映射 (Wiring Pinout)

为避免引脚冲突，系统对 Micro:bit 的硬件引脚进行了极其精准的分配与物理避让：

| 硬件外设 | 连接引脚 | 信号类型 | 功能描述 | 避让/调试注意事项 |
| :--- | :---: | :---: | :--- | :--- |
| **光敏电阻传感器** | **P0** | 模拟输入 (Analog) | 检测桥面实时光照强度 | **冲突注意**：IO:bit V2 板载蜂鸣器开关必须拨至 **OFF**，否则会拉低 P0 阻值导致读数异常！ |
| **超声波 Trig** | **P1** | 数字输出 (Digital) | 触发超声波测距信号 | - |
| **超声波 Echo** | **P2** | 数字输入 (Digital) | 接收超声波回响脉冲 | - |
| **电位器风速传感器** | **P3** | 模拟输入 (Analog) | 模拟风力传感器数值 | **冲突注意**：Micro:bit 内部 P3 引脚物理复用了 LED 矩阵第 1 列。**代码首行必须执行 `display.off()` 禁用屏幕**，否则读数会出现规律性大幅度脉冲跳变！ |
| **三色交通灯 - 绿灯** | **P12** | 数字输出 (Digital) | 正常通行引导灯 | - |
| **三色交通灯 - 黄灯** | **P13** | 数字输出 (Digital) | 减速慢行引导灯 | - |
| **三色交通灯 - 红灯** | **P14** | 数字输出 (Digital) | 强风禁止通行灯 | - |
| **有源蜂鸣器** | **P15** | 数字输出 (Digital) | 车辆通过音效 / 强风警报器 | - |
| **WS2812 暖光灯条** | **P16** | 信号输出 (Digital) | 模拟 12 颗大桥高杆路灯 | **功耗限制**：为了防止路灯全亮时瞬间拉低 5V 轨道电压导致 LCD 屏变暗/闪烁（Brownout），路灯亮度在算法中已被限制在超稳态低功耗值 `(8, 8, 4)`。 |
| **I2C LCD 1602 SDA**| **P20** | I2C 数据总线 | 中央多功能仪表盘 (I2C 地址 `0x27`) | 使用 1602A 字符液晶，必须接入板载的 5V 供电（3.3V 供电会导致背光极弱且无法显字）。 |
| **I2C LCD 1602 SCL**| **P19** | I2C 时钟总线 | 中央多功能仪表盘 (I2C 地址 `0x27`) | - |

## ⚙️ 核心控制逻辑

### 1. 车辆识别与高精度软件锁（防重复计数）
超声波探测距离低于 **20.0cm** 时视为有车驶入，立刻触发蜂鸣器瞬时鸣叫 40ms，计数器加 1。
为避免车辆在探头下静止或移动缓慢导致数值反复跳变，加入了高精度状态锁 `car_in_zone`。只有当测距数值完全恢复至 **25.0cm** 以上时，锁定才会解除，进入下一次计数循环。

### 2. 风速分级及行车决策
通过电位器模拟 0 - 1023 的风速值，系统实现三级动态决策：
*   **低风速 (0 - 400)**：正常通行。绿灯亮，黄红灯灭，LCD看板显示 `WIND: NORM`，行车引导状态 `STATUS: GO`。
*   **中风速 (401 - 800)**：减速慢行。黄灯亮，红绿灯灭，LCD看板显示 `WIND: MID`，行车引导状态 `STATUS: SLOW`。
*   **强烈台风 (> 800)**：禁止通行。红灯闪烁，绿黄灯灭，蜂鸣器发出持续的断续式警报，LCD看板显示 `WIND: STRG`，行车引导状态 `STATUS: STOP`。

### 3. 光感自动路灯系统（标定还原）
根据多次硬件实测与串口遥测数据，本光敏传感器（接于 P0 下拉分压）的实际行为如下：

> ⚠️ **特别注意**：此传感器的分压方向经实测证明与直觉相反，接手前请务必阅读！

*   **当松开手（光照强/白天）时**：ADC 读数**低**（约 `73`，`< 150`）→ 判定为 DAY，路灯熄灭。
*   **当用手遮住（光照弱/夜晚）时**：ADC 读数**高**（约 `267`，`>= 150`）→ 判定为 NIGHT，路灯点亮。
*   **阈值**：`150`（如更换环境或传感器，请先运行 `tools/diagnose_light.py` 重新标定）。

## 🚀 部署与使用说明

### 📦 0. 环境依赖安装（首次使用必读）
本项目的烧录与诊断工具需要 Python 3 及 `pyserial` 库：
```bash
pip3 install pyserial
```

### 🔌 1. 确认 USB 串口号
将 Micro:bit 通过 USB 连接到电脑后，**先确认你的串口号**（每台电脑可能不同）：
```bash
# macOS / Linux：
ls /dev/cu.usbmodem*

# Windows（在设备管理器查看，格式为 COM3 / COM4 等）
```
然后打开 `tools/flash.py`，将第 14 行的 `PORT` 变量修改为你实际的串口号：
```python
PORT = '/dev/cu.usbmodem14102'  # ← 改成你的串口号
```

### 🛠️ 2. 一键烧录主程序
在终端中定位到本项目目录下，使用我们编写的串口高可靠性行写入工具，直接将主程序写入 Micro:bit 中：

```bash
# 进入项目目录
cd /Users/John/.gemini/antigravity/scratch/hzm_bridge_safety_system

# 运行烧录指令（烧录主程序）
python3 tools/flash.py src/main.py
```

### 🔍 3. 硬件诊断工具使用
如果遇到传感器或硬件无反应，请使用 `tools` 目录下的专用小工具（烧录后通过串口监视器查看输出）：

| 问题现象 | 诊断工具 | 烧录命令 |
| :--- | :--- | :--- |
| LCD 不亮、无显示 | `diagnose_lcd.py` | `python3 tools/flash.py tools/diagnose_lcd.py` |
| 昼夜判断翻转 / 校准阈值 | `diagnose_light.py` | `python3 tools/flash.py tools/diagnose_light.py` |
| I2C 设备找不到 | `scan_i2c.py` | `python3 tools/flash.py tools/scan_i2c.py` |

**查看串口输出（运行诊断后）：**
```bash
# macOS / Linux
python3 -c "import serial,time; s=serial.Serial('/dev/cu.usbmodem14102',115200,timeout=1); [print(s.readline().decode(errors='ignore').strip()) for _ in range(60)]"
```

## 👨‍💻 后续维护与改进建议

1.  **外部独立供电**：若要让暖色路灯呈现出极佳的“黄金暖光大桥路灯”饱满视觉效果，建议切断扩展板与电脑的USB供电，改用外部 **5V 2A 稳压DC电源** 接入 IO:bit 的 USB 输入端。这样可以解锁路灯亮度限制，将 `(8, 8, 4)` 重新提升至 `(60, 60, 30)` 的高光亮级而不会导致屏幕变暗。
2.  **动态行车动画**：在未来扩展中，当检测到车辆驶入时，可以在 1602 屏幕的右下角通过自定义字符（Custom Char）动态绘制一个小车的像素动画，提升交互趣味性。
